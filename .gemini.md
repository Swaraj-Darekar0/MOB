# MOB Project Instructions & Rules

## Continuous Documentation & Feature Map Maintenance
- Any future agent or developer making modifications to existing features or adding new features in the MOB application must immediately update `MOB/.wiki/feature_map.md` with the updated feature specifications, exact source code file locations, and data flows.
- Always refer to `MOB/.wiki/INDEX.md` and `MOB/.wiki/feature_map.md` before making code changes to understand existing architecture, design tokens, SQLite schema, state slices, and payment/SMS workflows.

## Execution Constraints
- Never run `npm run dev` or `npm start` command; whenever you have to run that, ask the user to do it manually.
